# PrediBeacon internationalization policy

## Product rule

English (`en`) is the canonical and default public interface language. PrediBeacon is multilingual; Portuguese is not the product default.

Supported selector locales:

- English (`en`)
- Español (`es`)
- Português (`pt-BR`)
- Français (`fr`)
- Deutsch (`de`)
- Italiano (`it`)
- 日本語 (`ja`)
- 한국어 (`ko`)
- 简体中文 (`zh-CN`)
- العربية (`ar`)

The selected locale is persisted in the `predibeacon_lang` cookie. Unsupported or invalid locale values fail safely to English. Arabic uses RTL document direction.

## Translation safety

PrediBeacon uses controlled translation catalogs. Missing translations fall back to English; the application must not depend on browser automatic translation for product labels, contractual wording, legal/risk copy, or market-equivalence decisions.

Provider market titles and contract identity remain in their original source wording in the normalized API. UI localization must not mutate the title used for matching, attribution, routing or contract verification. A future translated display title may be added only as a separate presentation field.

The ambiguous English navigation word `Briefs` is normalized to `Insights`; Portuguese uses `Resumos` and Spanish uses `Resúmenes`.

## Cache boundary

Localized public HTML returns `Content-Language` and `Vary: Cookie` so a cached Portuguese/Spanish/etc. response cannot be served as the English default to another visitor.
